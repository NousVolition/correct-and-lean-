Can a fine-wave discrepancy reach broad waves?

This experiment asks whether a difference confined to fine velocity modes at tick 41 can produce a broad-mode difference as the coupled system evolves. It contains the measured histories, numerical controls, source code and exact starting state. The user proposed and directed the hypothesis; Codex generated and ran this analysis.

Yes, in this tested state and interval. The fine-wave difference shrank by 75.97%, while a small broad-wave difference developed. The full fluid, material, thermal, clay and actor feedback remained active.

What changed at the start

The two copies begin from the same saved post-write state at time 1.2, with three readable records. One copy receives a divergence-free velocity perturbation confined to 8 ≤ max(|kₓ|,|kᵧ|,|k_z|) ≤ 10. Its vector RMS is 0.01% of the initial velocity RMS: 5.5826977142e-07. The broad band is 1 ≤ max(|kₓ|,|kᵧ|,|k_z|) ≤ 2; the spatial mean is excluded.

Shape, position, material state, clay, warmth, context and actor state are identical initially. The perturbation is an initial-state difference; no new external input is added during evolution. Breathing remains off, the full original coupling stays active, and no new writes are scheduled in the interval.

Signed shares are projections onto the total rate-difference vector, so they sum to 100%. They are not energy-flux shares; the component RMS values do not add. This decomposition identifies the initial route only. Other coupled paths can contribute after their states diverge.

The direct component sum matches the full coupled rate subtraction to 2.79694e-06%. Evaluating the same retained input fields on 48³, 64³ and 96³ work grids checks these initial products. The native 32³ result differs from the 96³ evaluation by 2.25805e-05%; 64³ and 96³ agree to relative 1.2e-12. This supports the initial route beyond native-grid product aliasing. It is not a full spatial-refinement test of the evolving model.

What this establishes

An imposed fine-band velocity discrepancy can reach broad velocity modes in this coupled 32³ state while the fine discrepancy is being damped. The result survives the tested time-step and amplitude controls.

This experiment uses one perturbation direction, two amplitudes and a short interval. All time refinements start from the same saved state. It does not identify where the earlier simulation error originated, quantify an energy cascade, or show that this small broad difference causes the large return-miss changes in the frozen-field scan. That connection requires a matched geometric test using the evolving perturbed fields.
