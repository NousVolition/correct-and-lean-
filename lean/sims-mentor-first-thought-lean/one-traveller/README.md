## How continuity was checked

K27 was chosen as the first checkpoint in the earlier fixed order. The restaurant opened one live, tool-free actor thread and kept the connection open across the entire trial. At prime 2, B received its retained incident reference, the quiet pickup setting, the neutral receipt view and the original mentor line, “That was probably the pager—I pressed TEST earlier and saw it vibrate against your pocket.” Each subsequent room update reported only the elapsed quiet time. The original felt description and private embroidered motif were withheld. B’s own earlier replies remained in the same conversation.

The recorder checked each input and answer against the live server events. All 26 completed turns returned the same session identifier and distinct turn identifiers. The public records contain their fingerprints, original receipt digests, a sequential hash chain and separate wall-time readings. At each tick the open question came first. The second question asked for the current cause, level of certainty and basis. Neither recurring prompt named a device or a sensation. A single reviewer graded the first and second answer texts with tick labels and neighboring turns hidden, then restored the order. The repeated interviews and B’s own prior answers could influence subsequent words.
