## Can one multiplier fit both stored endpoints of this encounter?

`recorded_encounter_refutes_constant_ratio`

**Proof request**

Disprove the common-multiplier equation for the two stored endpoints at each specified reading and resolution.

**Reading the result**

For the recorded resolution and reading choices the two endpoint values violate the necessary common-ratio equation.

<details>
<summary>Exact Lean statement</summary>

```lean
theorem recorded_encounter_refutes_constant_ratio (z : Resolution) (r : Reading) :
    ¬ ∃ k : ℝ, readStored r (stored z .start)=k*(stored z .start).heat ∧
      readStored r (stored z .finish)=k*(stored z .finish).heat := by sorry
```
