## Can a valid A/S state drift outside its allowed bounds?

`full_state_invariance`

**Proof request**

Show that a solution satisfying the stated A/S hypotheses has a valid state at every time in [a,b].

**Reading the result**

The constructed solution obeys the bounds at every time in the interval. Uniqueness transfers them to any solution with the same start and inputs.

<details>
<summary>Exact Lean statement</summary>

```lean
theorem full_state_invariance : SocialAS.Open.FullStateInvariance := by sorry
```
